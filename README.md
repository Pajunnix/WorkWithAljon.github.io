# Aljon Villegas Portfolio v3

This version keeps the dark, high-contrast feel of the first draft while adding:
- Clickable navigation and CTAs
- Clickable Amazon/Shopify/work cards
- Animated counters and scroll-reveal position cards
- Floating/animated hero badges
- One verified Upwork feedback screenshot
- Clearly marked placeholders for future OnlineJobs.ph and WhatsApp screenshots
- Clickable tool/software logos
- Updated resume download
- WhatsApp, email and Upwork contact buttons

Important:
- The portfolio does not invent testimonials or falsely attribute feedback to OnlineJobs.ph or WhatsApp.
- Zillow is shown as a separate platform reference, not presented as a resume credential.
- The tool cloud includes software/platforms named in the updated resume and the requested platform logos.
